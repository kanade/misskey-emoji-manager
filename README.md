# misskey-emoji-manager

Misskey 向けの絵文字インポートツール「Emoji Manager」です。  
作成当時の Misskey にはタグやライセンスを確認しながらインポートする手段がなかったため、補助ツールとして作成しました。  
現在はカスタム絵文字管理（ベータ）によりある程度カバーされるようになりましたが、取得した一覧のブラウザへの保存（キャッシュ）や、テキストに含まれる絵文字コードからの抽出インポートなど、本ツールならではの機能も提供しています。

動作確認環境（2026/07/24現在の各最新版において確認）  
Misskey / Sharkey / Firefish（開発終了）

要検証  
Iceshrimp（非.NET版）、Iceshrimp（.NET版）

サイト上でそのままインポート作業を実行できます。  
https://tools.e17.dev/emoji-manager/

バグを見つけたらご報告いただけると助かります。

## ローカルでの実行

Node.js 20.19 以降（または 22.12 以降）が必要です。

```
yarn install
yarn dev
```

本番ビルドとプレビューは以下です。

```
yarn build
yarn preview
```

## 主な機能

- **一括インポート**: 指定サーバーの絵文字一覧をライセンス情報付きで取得し、検索・絞り込みをしながら選択してインポートします。
- **クリップボードインポート**: 貼り付けたテキストに含まれる絵文字コード（`:emoji_name:` 形式）を抽出し、指定サーバーから情報を取得して選択的にインポートします。
- **フォルダオプション**: アップロード先のドライブフォルダを「作成しない / 指定名 / 絵文字のカテゴリ名」から選べます。
- **進捗表示と途中停止**: 一覧の取得もインポートも、進捗バーを見ながら途中で停止できます。
- **ダークモード**: 右上のアイコンで切り替えられます（設定は保存されます）。
- **絵文字の確認**: 絵文字リストの画像クリックで拡大表示できます。

## 使い方

### 設定

右上の「設定」からインポート先の情報を登録します。設定はドメインごとに保存され、複数サーバーを切り替えて使えます。

- **インポート先のドメイン**: インポート先インスタンスのドメイン
- **絵文字用 API トークン**: 管理者権限の「絵文字を操作する」「絵文字を見る」を付与したトークン
- **ドライブ用 API トークン**: 「ドライブを見る」「ドライブを操作する」を付与したトークン

現在の Misskey では絵文字の画像はアップロードしたユーザーのドライブに保存されるため、絶対に消さない絵文字管理専用アカウントの利用をおすすめします。権限が適切に付与されていれば、両方に同じトークンを指定することもできます。  
Sharkey については絵文字登録に成功するとシステムアカウントのドライブに移動されます。

### 一括インポート

インポート元のドメインを入力し、初回は「サーバーから取得」を押してください。  
取得した一覧はブラウザ内（IndexedDB）にドメインごとに保存されるため、2回目以降は「保存済みデータを読み込む」で通信せずに表示できます。サーバー側で絵文字の更新があった場合など、最新のデータが必要なときだけ「サーバーから取得」を使ってください。

ライセンス情報は絵文字1件ずつの取得が必要なため、絵文字数や通信環境によっては取得に長い時間がかかります。取得は少数ずつ間隔を空けて行いますが、相手サーバーに負荷がかかるため短時間に繰り返さないでください。取得中の内容は 100 件ごとに保存されるので、途中で停止・中断しても取得済みの分は残ります。

一覧では検索で絞り込んだうえで、ヘッダーのチェックボックスから絞り込み結果だけを全選択できます。行のどこをクリックしても選択できます。ローカル限定の絵文字は選択できません（インポート対象外）。

### クリップボードインポート

絵文字コードを含むテキストを貼り付けて「絵文字を抽出」を押すと、コードを抽出して情報を取得します。一括インポートで取得済みのドメインならキャッシュが使われ、通信は最小限になります。  
`:name@host:` 形式（リモート由来の表記）は対象外です。

### インポート

インポート先をプルダウンで選び（設定済みのドメインから選択）、選択した絵文字をインポートします。  
処理は「画像 URL をドライブへアップロード → ドライブのファイルを絵文字として登録」という流れで、1件ずつ順番に実行されます。同名の絵文字がインポート先に既に存在する場合は事前チェックでスキップされるため、重複登録にはなりません。  
カテゴリ・エイリアス・ライセンスもそのまま取り込まれます。必要に応じて Misskey の管理画面から変更してください。

## ご利用上の注意

- API トークンや設定はブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません。
- 絵文字一覧のデータはブラウザ内（IndexedDB）に保存されます。
- 削除操作は行いませんが、事前に絵文字全体のバックアップを取ることをおすすめします。
- 通信量が多いため、相手サーバーに負荷をかける使い方はしないでください。
- 動作確認はしていますが、ご利用はすべて自己責任でお願いします。
- 取得がすぐ止まる、404 などのエラーが出る場合は非対応のサーバーの可能性があります。その場合は `@kanade@mfmf.club` までご連絡ください。インポート元のサーバー管理者への問い合わせはご遠慮ください。
